# 룸노트 테스트 사이트

작업실 배치도와 장비 관리 기능을 샘플 데이터로 체험하는 정적 웹사이트입니다. GitHub Pages에서 서버 없이 실행됩니다.

- 방 배치도: 1~11번 방, 1·2번 가공실, 블리스터, 공급실.
- 건조기/섞는 기계 현황 전환, 드래그 이동, 두 손가락·마우스 휠 확대.
- 이용 품목과 시작 시간, 예약, 주사기 제작 준비 제품·수량·상태.
- ID별 메모 추가·삭제, 수정·취소·적용.
- 새로고침 또는 체험 초기화 시 샘플 상태로 복원합니다.

실제 계정 로그인·서버 저장·다른 방문자와 기록 공유는 제공하지 않습니다. 입력한 내용을 서버로 전송하거나 브라우저 저장소에 보관하지 않습니다.

## GitHub Pages로 공개

1. 공개 저장소 `roomnote-demo`를 만듭니다.
2. 이 폴더의 `index.html`을 저장소 최상위에 업로드합니다. README.md와 .nojekyll도 함께 올릴 수 있습니다.
3. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, **main**, **/(root)**를 선택하고 Save 합니다.
4. 배포 완료 후 Pages에 표시되는 주소로 접속합니다. 실제 주소가 확인되기 전에는 공개 완료로 간주하지 마세요.

`index.html`은 필요한 화면·코드·아이콘을 포함한 단일 파일입니다. PC 또는 휴대폰에서 같은 파일을 사용합니다. Python/Android SDK/APK/서명 키/로컬 기록 파일은 공개할 필요가 없습니다.

## 로컬 업데이트

기존 프로젝트의 모바일 체험 화면에서 공개 파일을 재생성합니다.

```powershell
py -3.12 D:/cod/roomnote-pages/build_site.py
```

생성된 index.html을 GitHub에 다시 반영하면 됩니다.
